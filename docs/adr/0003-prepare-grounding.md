# 0003. Подстановка имён в prepare

## Контекст

Модель вызывала `prepare_tariff_change` с выдуманными именами (`UltraPlus`, `Престиж`) или подменяла «Семейный» на «Игровой». Карточка либо не создавалась, либо сценарий 30 ждал неверный тариф в моках.

## Решение

- На ход пишем `session.last_user_message`.
- В `wrap` перед MCP-вызовом `_ground_prepare_args`: если в реплике есть имя из каталога стенда, подставляем его в `tariff` / `service`; для услуг также выводим `enabled` из «включи/отключи».
- Нормализация в action-MCP остаётся; grounding — страховка от галлюцинации аргумента.

## Альтернативы

- Только усиление промпта tariff-агента.
- Fuzzy-match внутри `normalize_tariff` без связи с репликой.
- Запрет prepare без точного совпадения каталога на стороне PEP.

## Когда пересмотреть

Расширение каталога тарифов/услуг; мультиязычные названия; или модель стабильно передаёт канонические имена на новой связке.
