# 0002. Гейт планировщика

## Контекст

Матрица `make scenarios` на Qwen2.5-7B плавала: на «почему списание…» иногда приходила карточка; иногда план был пустым с уточняющим вопросом (замер планов ~1/30). Смок без LLM этого не ловил.

## Решение

- `planner.wants_write(message)` — детерминированно: вопрос/«расскажи»/отмена → чтение; глагол действия или намерение («хочу», «давай») → запись; реплика с «?» без намерения → чтение.
- `gate(plan, message)` отбрасывает шаг `tariff`, если реплика не просит изменение. Без `message` поведение прежнее (аддитивно).
- На чтении пустой план (в т.ч. с уточняющим вопросом планировщика) заменяется на `data`+`kb`.
- Smoke-группа `G=7` проверяет гейт без стенда и LLM.

## Альтернативы

- Крутить temperature / повторять сценарии до зелёного.
- Убрать tariff из каталога планировщика на read-фразах промптом (всё ещё вероятностно).
- Жёсткий whitelist только известных реплик матрицы.

## Когда пересмотреть

Смена модели планировщика на более послушную; или появятся write-фразы без слов из списков стеблей — расширить списки по факту красных сценариев.
